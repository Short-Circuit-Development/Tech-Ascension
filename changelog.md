# Changelog
 
All notable changes to Tech Ascension will be documented here.
 
## [0.0.0] - Initial Development
 
### Added
- Created the initial Tech Ascension project.
- Established the initial modpack structure.
- Assembled the initial mod selection for Minecraft 1.21.1.
- Added the initial technology, automation, survival, exploration, building, and quality-of-life mods.
- Added TerraFirmaCraft and its supporting addons.
- Added GregTech.
- Added Create and its supporting addons.
- Added Applied Energistics 2 and its supporting addons.
- Added Mekanism and supporting integrations.
- Added Ad Astra and other space-related content.
- Added KubeJS and KubeJS TFC for future pack customization.
- Added performance and optimization mods.
- Created the initial full mod list.
 
### Changed
- Began testing the complete modpack environment.
- Began compatibility and performance testing.
- Established Minecraft 1.21.1 with NeoForge as the initial development platform.
 
### Removed
- Removed Chunky 1.4.23 due to a crash involving its interaction with Distant Horizons during chunk generation/loading.
 
### Fixed
- Fixed world loading/chunk generation crashes caused by the Chunky and Distant Horizons interaction by removing Chunky.
 
### Known Issues
- Performance requirements are currently extremely high.
- Memory usage and overall pack performance require further optimization.
- Mod compatibility testing is ongoing.
 
### Development Status
Tech Ascension is currently in very early development.
 
Version 0.0.0 represents the initial foundation of the project and is not intended to be considered a finished or stable release.
